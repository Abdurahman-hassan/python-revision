

# Repositorio de Repaso de Python

¡Bienvenido al Repositorio de Repaso de Python! Este repositorio contiene material educativo de diversos tutoriales de Python disponibles en Udemy, YouTube y TutorialsPoint, junto con mejoras aportadas por mí. 

Ya sea que seas nuevo en Python o un desarrollador experimentado que busca profundizar en su comprensión, encontrarás aquí abundante contenido para ayudarte.

## Acerca de

El Repositorio de Repaso de Python es mi iniciativa para aprender Python de manera más efectiva y también compartir conocimiento con otros. Es una colección de fragmentos de código, comentarios y explicaciones sobre diferentes temas en Python, todo organizado en cuadernos Jupyter para facilitar la comprensión. 

Los materiales de este repositorio se basan en diversos recursos en línea, incluidos cursos de Udemy, videos de YouTube y tutoriales del canal TutorialsPoint. Si bien estos materiales proporcionan la base, también he incluido mis propias mejoras y explicaciones adicionales para enriquecer la experiencia de aprendizaje.

## Contenido

El repositorio está dividido en varias secciones, cada una dedicada a un tema diferente en Python:

- Sintaxis básica
- Fundamentos de Python
- Variables
- Tipos de datos
- Control de flujo
- Funciones
- Manejo de excepciones
- Entrada/Salida de archivos
- Implementación de arrays
- Métodos de archivos
- Palabras clave e identificadores
- Tuplas de Python
- Estructuras de datos
- Programación Orientada a Objetos con Python
- Programación Funcional con Python
- shallow copy vs deepcopy
- Lambdas
- Decoradores
- Generadores
- Pruebas en Python
- Depuración
- Expresiones regulares
- Comprensiones
- Módulos
- Temas avanzados

Cada sección contiene ejemplos de código y explicaciones correspondientes.

El código se encuentra dentro de cuadernos Jupyter (archivos .ipynb) para un aprendizaje interactivo. Se incluyen imágenes para aclarar ciertos conceptos. Si tienes problemas para ver las imágenes en la vista previa del cuaderno, por favor clona este repositorio y ejecuta los cuadernos en tu entorno Jupyter local.

## Uso

Para utilizar el Repositorio de Repaso de Python:

1. Clona este repositorio en tu máquina local usando `git clone https://github.com/Abdurahman-hassan/python-revision`.

2. Navega hasta el repositorio clonado.

3. Recorre los directorios y archivos en el orden sugerido anteriormente, o elige un tema específico que te interese.

4. Ejecuta cualquier archivo .ipynb utilizando Jupyter Notebook.
